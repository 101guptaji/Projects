Variables

variable is an entity which store the value of defined data type, means the type of variable should be same of the type of value.But programming language like javascript and python are said loosely language, so here you don't need to explicitely define the variable type whatever value you assign to variable, the type of variable becomes the type of value.

Rules for variable creation followed in programming languages are :
  • The variable name always starts with alphabet letter or underscore.
  • Never use keyword, function, defined data types as variable name.
